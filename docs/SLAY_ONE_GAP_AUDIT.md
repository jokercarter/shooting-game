# Morrow Fields 与 Slay.one 差距审计

审计时间：2026-10-02（America/New_York）

对照来源：[Slay.one 官方首页](https://slay.one/) 和公开客户端 [client-bundle.js](https://slay.one/dist/client-bundle.js)。官方页面仍以全屏 `canvas` 为战场，并包含大厅全局聊天、好友/战队入口、排位搜索、房间与地图投票、战中排行榜、小地图、复活、战果结算和设置面板。公开客户端中还能看到 `showFPS`、`showPing`、`mode2Weapon`、`replay`、`friends`、`clan` 等功能标识。

当前 Morrow Fields 已覆盖：

- 全屏 Canvas 战场、原创像素角色/地图/武器、3000×2000 世界和跟随镜头；人物移动有轻微交替步伐，身体仍保持直立，死亡等待时镜头平滑跟随存活玩家并支持 `[` / `]` 切换。
- 房间码、开放房间列表、大厅聊天、WebSocket 多人同步、20/24/2 人容量、机器人和断线清理。
- 六种模式、15 个武器槽位、固定补给点、装填进度反馈、浮动伤害数字、治疗光束、能量副射击、追踪/反弹/爆炸/蓄力行为。
- 小地图、排行榜、死亡倒计时、技能点、升级、皮肤选择、移动端控制、河流/桥梁和导弹击飞落水死亡。
- 本地服务和局域网地址均可运行；v62 本机实战已验证低人数和 8 人共享状态下的武器拾取，装备栏和弹药同步正常，页面 FPS 读数达到 `100`。10 个同机 WebSocket 客户端连续10分钟移动/射击测得状态间隔 P95 `12.96ms`、最大 `21.84ms`，0/539,960 超过 25ms，RTT P95 `3.44ms`；同机 10 秒 LAN 接口样本也未超过25ms。这些模拟不代表另一台设备的端到端网络。防火墙规则仍指向已搬走的 `.venv` Python 路径，管理员运行 `open-arena-lan-firewall.ps1` 后才适合做实体设备验收。

主要差距按优先级排列：

| 优先级 | 差距 | 当前状态 | 建议下一步 |
|---|---|---|---|
| P0 | 地图投票和战后换图 | 已实现战后地图投票；所有真人完成投票后在原房间重置地图、比分、武器和出生点；15 秒超时自动开局，平票保留当前地图 | 后续可增加投票动画和更明确的平票提示 |
| P0 | 战后结果与复活流程 | 已补充战后结果面板；死亡倒计时保留 | 后续加入奖励、经验和正式重开局状态 |
| P0 | 稳定公网服务 | Quick Tunnel 可用但不保证长期在线，房间只在内存中 | 完成支持 WebSocket 的正式托管、持久化账号和房间恢复策略 |
| P1 | FPS、Ping 和画面选项 | 实时 FPS、RTT、状态频率和画面设置已实现；v62 本机对局达到 `100 FPS`，既有 10 人高负载浏览器样本为 `60.3 FPS` | 用 v62 重测 10 人浏览器绘制帧率，复测实体设备长时间尾部和 16 人以上拥挤分支 |
| P1 | 排位搜索与好友/战队 | 有房间码和大厅聊天，没有账号社交关系 | 先做匿名好友邀请，再增加账号、好友、战队和排位队列 |
| P1 | 回放与观战 | 已有死亡观战镜头、目标切换、战后最近约 12 秒 JSON 导出、带暂停/继续/时间轴拖动的本地播放器和大厅观战入口 | 后续增加更细的观战者权限、目标锁定和更长回放存储 |
| P2 | 经济、宝箱和长期进度 | 有技能点和本局分数，没有账号资源 | 在账号系统之后增加资源、宝箱和长期解锁 |
| P2 | 视觉资产和地图细节 | 采用自己的名称、素材和地图，障碍物已拆成短块、石堆和切角墙体 | 继续增加有地标的地图路线、桥梁、岸线、粒子和命中特效 |

本轮新增战后结果面板、地图投票、投票超时/平票处理、投票进度条、实时 RTT、本地画面设置、合成音效、受击/击杀确认反馈、装填进度反馈、带时间轴的短回放播放器和大厅观战入口：浏览器实际显示 `FPS 60 · RTT 1ms · STATE 20Hz`，低特效/隐藏小地图/隐藏武器栏/小地图尺寸/音量能保存到 `localStorage`；本地 JSON 回放已现场进入 `LOCAL REPLAY`，暂停、拖动和继续播放均通过，正式观战已进入 `SPECTATING`，播放结束后回到大厅并清理 HUD，控制台无错误。后续可增加更细的观战者权限、更长回放存储、分类型音效设置和稳定托管。账号、好友、战队、经济依赖持久化数据与正式部署，单靠当前进程内房间无法可靠完成。

视觉和命名继续保持原创；对 Slay.one 的对照只用于功能和体验审计，不复制其商标、贴图、地图文件或源码。

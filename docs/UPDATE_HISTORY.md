# Morrow Fields 更新历史

## 2026-10-02

- 完成三张原创像素地图：Mosswood Crossing、Sunvale Orchard、Redleaf Ruins。
- 增加河流、桥梁、分散掩体、树木、岩石、箱子、草丛和尖刺。
- 增加 15 种武器、固定武器补给点、装填、弹药和武器栏同步。
- 增加血包、护甲和补给重生提示；护甲会吸收部分伤害。
- 修正弹道碰撞：实体障碍物会阻挡武器，草丛不会阻挡弹道。
- 增加草丛可见性规则：同一草丛互相可见，开火或受伤后暴露 3 秒。
- 增强导弹爆炸：像素冲击波、碎片、烟尘、全屏闪光和镜头抖动。
- 增加房间码联机、机器人、旁观、聊天、地图投票和短回放。
- 增加高 DPI Canvas 渲染，改善高分辨率屏幕上的像素清晰度。
- 增加本地、局域网、临时公网和 Docker / Render 启动方式。

## 设计原则

游戏使用自己的名称、地图、角色、武器和像素素材。Slay.one 仅作为玩法与交互体验的参考，不复制其商标、贴图、地图文件或源码。

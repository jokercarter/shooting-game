## 2026-10-19 小地图：视野框 + 视野内才显示敌人 + 草丛隐身

## 2026-10-19 爆炸抖动改为「视野内 + 距离衰减」

- 旧衰减半径只有 `max(420, blast*6)`（约 492px），3000×2000 的地图上绝大多数爆炸完全不抖；且白屏闪光不随距离缩放，地图另一头的火箭照样致盲。
- 新模型两条规则：**① 只在视野内的爆炸才算**（`visibleRect` + 140px 余量，屏幕外一律为 0）；**② 屏幕内按与视野的距离衰减**，越近越猛。
- 距离取「相机」与「视野主体（spectatorTarget || localPlayer）」中较近的一个——相机在地图边缘会被钳制，若不这样处理，贴脸火箭会因为相机被墙挤偏而只算出半屏距离。
- 爆炸白屏闪光改为乘以同一距离系数，远处爆炸不再致盲。
- 抖动改为「峰值 + 少量叠加」并设上限（镜震 46 / 屏震 60）：一发近爆始终最强，但多方向同时爆炸会叠成持续轰鸣，而不是只保留最猛那一次。
- 附带性能收敛：屏幕外不再生成烟雾粒子；光环绘制按可见范围裁剪。
- 实测（火箭 blast 82）：贴脸 1.00 → 120px 0.69 → 260px 0.41 → 屏幕外 0。

# slay.one 参考拆解（不含原始素材）

> **重要**：本文件不含、也不提供对方任何图片文件。以下数据全部来自实机画面的人工观察与比例估算，用于指导**我们自己的原创重绘**，不做资产搬运。
> 估算精度：色相 ±1 阶、尺寸 ±8px。需要精确值时，请按 §5 的方法自己量。

---

## 1. 一句话结论

slay.one 的画面不是"画得细"，而是**每个材质只有一个色系、一层描边、一个固定纹理尺寸**。只要这三件事对齐，观感立刻靠近；细节多少影响很小。

---

## 2. 背景地图

| 项目 | 观察值 | 我们的现状 | 建议 |
|---|---|---|---|
| 世界瓦片 | 约 64px（石墙按此对齐） | 100px | 保持 100px（碰撞数据依赖），只把**纹理单元**降到 32px |
| 草地纹理 | 约 8px 的棋盘格 + 2px 细点，密度约 12 个/100px² | 草叶 3 根 + 细点 9 个 | 已补细点到 9 个/格，可再加一层 8px 微棋盘 |
| 草地明度差 | 主色与纹理色相差 ≤ 8% | 约 10% | 可再压 2%，让角色更跳 |
| 道路 | 与草地同尺寸的方块，纯色无纹理 | 同 | 保持 |
| 水域 | 纯色 + 一条更亮的边，宽约 3px | 渐变 + 泡沫边 | 可简化为 2 段色，减少"塑料感" |
| 边界 | 一整圈石墙，厚度 1 格 | 石砌护堤 | 保持 |
| 暗角 | 几乎看不到（≤10%） | 18% | 已从 34% 降下来，可再降到 12% |

**关键点**：草地是"低对比 + 高密度小纹理"，不是"大色块 + 大装饰"。

## 3. 障碍物

| 类型 | 观察结构 | 比例 | 我们的对应 |
|---|---|---|---|
| 石墙 | 顶面亮、侧面暗、横向砖缝，单块约 64×64 | 高:宽 ≈ 1:1，成组出现 | `obstacle-wall.svg`（180×100，偏扁长）→ 可改 1:1 块再拼 |
| 木箱 | 深色外框 + 中间浅色面板 + 对角加固 | 约 48×48 | `obstacle-crates.svg` |
| 树 | 深绿冠 + 亮绿受光面，冠径约 96px | 冠:干 ≈ 3:1 | `obstacle-tree.svg` |
| 圆木/木桶 | 圆柱 + 端面年轮 | 直径约 40px | `obstacle-stump.svg` |
| 尖刺 | 底面石台 + 4–5 根三角刺 | 高约 32px | `obstacle-spikes.svg` |

**描边规律**：外轮廓 3–4px 近黑；**内部结构不加线**，只用明暗两阶。我们目前是 5px，偏粗，可降到 4px。

**投影**：几乎没有独立投影，靠"侧面暗色"贴地。我们的 22% 椭圆投影可以减到 14%，或只保留在树/箱上。

---

## 4. 角色与武器（顺带）

- 角色约 40px 高，头身比 ≈ 1:1.6，四肢只有色块，没有肘膝关节。
- 外套是画面里**唯一高饱和**的颜色（红/蓝/黄），其余全部降饱和。
- 武器是角色宽度的 1.2–1.5 倍，枪口只有 2–3px 的高光点。
- 血条：宽约 32px、高 4px，深色外框 + 纯绿填充，无渐变。

## 5. 自己量参数的方法（合法且够用）

1. 进对局，把画面截成 PNG。
2. 取一块纯草地，放大到 800%，数一个棋盘周期有多少像素 → 纹理单元尺寸。
3. 用取色器点 5 个点，取中位数 → 主色；再点 3 个暗部 → 暗面。
4. 量石墙单块在屏幕上的像素宽 → 除以镜头缩放 → 世界瓦片尺寸。
5. 量描边像素宽度 → 除以缩放 → 设计稿线宽。

## 7. 还没做、需要你拍板的三项

1. **石墙改 1:1 方块拼接**：更接近参考，但要改 `MAPS` 的碰撞矩形（后端数据）。
2. **描边 5px → 4px**：更接近参考的克制感，全局一致，风险低。
3. **去掉大部分障碍物投影**：更贴近"靠侧面暗部贴地"的做法，风险低。

前两项会影响手感，第三项是纯视觉。
